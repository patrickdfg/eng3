# WordStep 학생 영어

모바일에서 필수 영단어를 카드, 예문, 발음, 퀴즈로 학습하는 정적 웹 앱입니다. 빌드와 API 키가 필요하지 않습니다.

## 실행

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다. GitHub Pages는 저장소 루트에서 바로 배포할 수 있습니다.

## 구현 기능

- 중학교 핵심 단어 200개, 품사·뜻·예문 3개와 해석
- 단어·예문 발음(Web Speech API), 3초 자동 넘김(기본 정지)
- 이전/다음, 키보드 방향키, 모바일 좌우 스와이프
- 검색·카테고리, 오늘의 10개, 즐겨찾기
- 4지선다 10문제, 점수, 오답 자동 저장·복습
- 학습 완료·연속 학습일을 브라우저에 보존
- 360px 이하 휴대폰부터 데스크톱까지 반응형
